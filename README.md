# Money Control

Aplicación para llevar el control de cuentas bancarias, gastos e inversiones.

## Estructura del proyecto

Este repositorio está dividido en dos ramas principales:

- **`claude/finance-management-app-aPtlv-backend`**: Backend construido con Python, FastAPI, PostgreSQL y Docker.
- **`claude/finance-management-app-aPtlv-frontend`**: Frontend con interfaz similar a Revolut.

## Funcionalidades

- Gestión de cuentas bancarias y efectivo
- Registro de gastos e ingresos
- Seguimiento de inversiones con cálculo de crecimiento anual (%)
- Dashboard con resumen del patrimonio total

## Cómo empezar

1. Revisa la rama del backend para ver las instrucciones de instalación del API.
2. Revisa la rama del frontend para ver las instrucciones de instalación de la interfaz.
